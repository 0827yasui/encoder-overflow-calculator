
# Encoder Overflow Calculator

インクリメントロータリーエンコーダのカウント値をマイコンのタイマカウンタで取得する際、**カウンタのオーバーフロー／アンダーフローによる回転方向の誤判定を防ぐための設計条件**を自動計算するGUIツールです。

## 主な機能

* **オーバーフロー判定:** 入力された条件で1サンプリング周期内のカウント変化量が許容範囲内に収まるかを判定し、余裕度（%）を表示します。
* **設計上限値の逆算:** 現在の条件から許容される「最大エンコーダ分解能（$N_{res}, N$）」および「最大サンプリング周期（$T_s$）」を自動算出します。
* **単位変換対応:** 最大角速度は `rad/s` と `rpm` の切り替え、サンプリング周期は `ms` 入力に対応しています。

## 動作環境

* Python 3.x
* 標準ライブラリ（`tkinter`, `math`）のみで動作するため、追加パッケージのインストールは不要です。

## 使い方

1. リポジトリをクローンまたはダウンロードします。

   ```bash
   git clone https://github.com<ユーザー名>/encoder-overflow-calculator.git
   cd encoder-overflow-calculator
   ```
2. スクリプトを実行します。

   ```bash
   python encoder_calc_ui.py
   ```
3. 画面上で以下のパラメータを入力し、「計算実行」をクリックします。

   * **カウンタビット数 $b$ [bit]:** 使用するタイマカウンタのビット幅（8, 16, 32など）
   * **基本パルス数 $N$ [PPR]:** エンコーダ1回転あたりのパルス数
   * **逓倍数 $k$ [-]:** 2逓倍 または 4逓倍（$k \in \{2, 4\}$）
   * **最大角速度 $\omega_{max}$:** 想定される入力軸の最大回転速度（`rad/s` または `rpm`）
   * **サンプリング周期 $T_s$ [ms]:** カウント値を読み取る制御周期

## 計算理論・数式

本ツールは以下の理論式に基づいています。

### 1. 1サンプリング周期内の最大カウント変化量

1回転あたりの総カウント数 $N_{res} = kN$ 、最大入力軸角速度を $\omega_{max}\ \mathrm{[rad/s]}$ 、サンプリング周期を $T_s\ \mathrm{[s]}$ とすると、1サンプリング周期内の最大カウント変化量 $\Delta C_{max}\ \mathrm{[count]}$ は次式で表されます。

$$
\Delta C_{max} = \frac{N_{res}\omega_{max}T_s}{2\pi} = \frac{kN\omega_{max}T_s}{2\pi}
$$

### 2. オーバーフロー判定条件

タイマカウンタのビット数を $b\ \mathrm{[bit]}$ とすると、計数周期は $M = 2^b$ （値域：$0 \sim 2^b - 1$）となります。前回値と今回値の差分から回転方向を正しく判定するには、カウント変化量を計数周期の半分未満に抑える必要があります。

$$
|\Delta C_{max}| < \frac{M}{2} = 2^{b-1}
$$

### 3. 設計上限値（分解能・サンプリング周期）

上記の条件式を変形することで、システム設計における上限値を算出します。

* **許容されるエンコーダ分解能の上限:**

  $$
  N_{res} < \frac{2\pi \cdot 2^{b-1}}{\omega_{max}T_s}, \quad N < \frac{2\pi \cdot 2^{b-1}}{k\omega_{max}T_s}
  $$
* **許容されるサンプリング周期の上限:**

  $$
  T_s < \frac{2\pi \cdot 2^{b-1}}{N_{res}\omega_{max}} = \frac{2\pi \cdot 2^{b-1}}{kN\omega_{max}}
  $$

### （参考）C言語での実装例

上記条件を満たす場合、符号なし整数型（`uintb_t`）のカウンタ差分を符号付き整数型（`intb_t`）へキャストするだけで、オーバーフロー判定の条件分岐なしに正確な変化量と回転方向を取得できます。

```c
uint16_t last; // 前回のカウンタ値（16bitの例）
uint16_t now;  // 現在のカウンタ値
int16_t  num = (int16_t)(now - last); // カウント変化量と回転方向
```
