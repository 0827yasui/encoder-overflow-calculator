# Encoder Overflow Calculator

インクリメンタル型ロータリーエンコーダのパルスをマイコンのタイマカウンタで計数するとき、**カウンタのオーバーフロー／アンダーフローによって回転方向を誤判定しないための設計条件**を計算する GUI ツールです。

## 主な機能

- **オーバーフロー判定**：1 サンプリング周期あたりの最大カウント変化量が許容範囲に収まるかを判定し、余裕度 [%] を表示します。
- **設計上限値の逆算**：現在の条件で許容される「エンコーダ分解能の上限」と「サンプリング周期の上限」を算出します。
- **単位の切り替え**：最大角速度は `rad/s` と `rpm` を選択でき、サンプリング周期は `ms` で入力します。

## 動作環境

- Python 3.x
- 標準ライブラリ（`tkinter`, `math`）のみ使用。追加パッケージは不要です。

## 使い方

```bash
git clone https://github.com/0827yasui/encoder-overflow-calculator.git
cd encoder-overflow-calculator
python encoder_calc_ui.py
```

起動後、以下のパラメータを入力して「計算実行」を押します（起動時は初期値で計算済みです）。

| パラメータ | 記号 | 単位 | 初期値 | 説明 |
| --- | --- | --- | --- | --- |
| カウンタビット数 | $b$ | bit | 16 | タイマカウンタのビット幅（8 / 16 / 32 など） |
| 基本パルス数 | $N$ | PPR | 1024 | エンコーダ 1 回転あたりのパルス数 |
| 逓倍数 | $k$ | – | 4 | 2 逓倍または 4 逓倍 |
| 最大角速度 | $\omega_{\max}$ | rad/s / rpm | 314.16 rad/s | 想定する入力軸の最大回転速度 |
| サンプリング周期 | $T_s$ | ms | 1.0 | カウンタ値を読み取る制御周期 |

### 計算例（初期値）

$N_{\mathrm{res}} = 4 \times 1024 = 4096$ 、 $\omega_{\max} = 314.16$ rad/s（約 3000 rpm）、 $T_s = 1$ ms のとき、

- 最大カウント変化量 $\Delta C_{\max} \approx 204.8$ count
- 許容上限 $2^{15} = 32768$ count
- 判定：**OK**（余裕度 約 99.4 %）

## 計算理論

### 1. 1 サンプリング周期あたりの最大カウント変化量

1 回転あたりの総カウント数を $N_{\mathrm{res}} = kN$ とすると、1 サンプリング周期内の最大カウント変化量 $\Delta C_{\max}$ [count] は次式で表されます。

```math
\Delta C_{\max} = \frac{N_{\mathrm{res}}\,\omega_{\max}\,T_s}{2\pi} = \frac{kN\,\omega_{\max}\,T_s}{2\pi}
```

### 2. オーバーフロー判定条件

$b$ ビットカウンタの計数周期は $M = 2^b$ （値域 $0 \sim 2^b - 1$ ）です。前回値と今回値の差分から回転方向を正しく判定するには、カウント変化量を計数周期の半分未満に抑える必要があります。

```math
|\Delta C_{\max}| < \frac{M}{2} = 2^{b-1}
```

### 3. 設計上限値

上の条件式を変形すると、設計上の上限値が得られます。

**エンコーダ分解能の上限**

```math
N_{\mathrm{res}} < \frac{2\pi \cdot 2^{b-1}}{\omega_{\max}\,T_s}, \qquad
N < \frac{2\pi \cdot 2^{b-1}}{k\,\omega_{\max}\,T_s}
```

**サンプリング周期の上限**

```math
T_s < \frac{2\pi \cdot 2^{b-1}}{N_{\mathrm{res}}\,\omega_{\max}} = \frac{2\pi \cdot 2^{b-1}}{kN\,\omega_{\max}}
```

## 参考：C 言語での差分計算

上記の条件を満たしていれば、符号なし整数のカウンタ差分を同じビット幅の符号付き整数へキャストするだけで、オーバーフローの場合分けなしに変化量と回転方向を取得できます。

```c
uint16_t last;                         // 前回のカウンタ値（16 bit の例）
uint16_t now;                          // 今回のカウンタ値
int16_t  delta = (int16_t)(now - last); // 変化量（符号が回転方向）
```
